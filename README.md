## 🌐 Architecture & Features

- **Fullstack React + Express Hub:** Clean separation of concerns between responsive front-end components and a RESTful backend.
- **Event-Driven Ticket Lifecycle:** Tracks issue status from initiation through triage, resolution, and verification.
- **Robust Failure Resilience:** Built-in network retry policies with exponential backoff and localized Spanish error reporting.
- **Automated CI/CD Hooks:** Pre-configured environment templates (`config/env.example`) and Jest test scaffolds.
